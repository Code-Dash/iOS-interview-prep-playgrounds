# Downloads

This folder contains reader downloads for The iOS Interview Handbook:

- **iOS-Interview-Rapid-Sheet.md** / **.pdf** — Rapid drill sheet for interview practice
- **iOS-Interview-Prep.docx** — Full book as Word document
- **iOS-Interview-Prep.epub** — Full book as EPUB (Apple Books, Kindle, etc.)

Generated by `scripts/generate_word_doc.py` (and `generate_rapid_sheet.py`) in the main book repo. Run from the book repo with the playground repo as a sibling, or set `PLAYGROUND_REPO` to this repo's path.
